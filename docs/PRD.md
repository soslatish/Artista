# Artista — требования к MVP (PRD)

> Источник: бизнес-план (январь 2026), приложения А/Б (P&L, ДДС), отчёт по 2 этапу.
> Модель — **маркетплейс оригинальных произведений искусства** (бизнес-план). Старая модель
> «исполнитель/заказчик/услуги» из прошлых макетов признана устаревшей.

## 1. Суть

Мобильное приложение (iOS + Android) для прямой продажи работ от художников покупателям.
Галереи берут 30–50%, Artista — 15%. Деньги покупателя удерживаются до подтверждения
получения (эскроу), затем выплачиваются художнику.

## 2. Роли

| Роль | Что делает |
|---|---|
| Покупатель | ищет и покупает работы, ведёт избранное, подписывается на художников, пишет в чат, оставляет отзывы |
| Художник | всё то же + публикует работы, обрабатывает заказы, видит статистику, может купить премиум |
| Администратор | разбирает жалобы, скрывает контент (через API, без отдельной админки в MVP) |

Роль выбирается при регистрации; покупатель может стать художником в профиле.

## 3. Монетизация (из бизнес-плана)

- Регистрация и размещение работ — бесплатно.
- Комиссия платформы — **15%** от цены работы, удерживается из выплаты художнику.
- **Премиум художника — 990 ₽/мес**: приоритет в выдаче, расширенная статистика,
  **0% комиссии** на продажи до 100 000 ₽ в календарный месяц (сверх — 15%).
- Цена работы: от 3 000 до 500 000 ₽.
- Доставка: Москва/СПб 500–800 ₽, регионы 1 000–3 000 ₽, бесплатно от 50 000 ₽.

## 4. Функции MVP

### Аккаунт
- Регистрация/вход по e-mail и паролю; JWT (access 15 мин + refresh 30 дней, ротация).
- Восстановление пароля кодом из письма (отправка писем — **заглушка**, код пишется в лог).
- Профиль: имя, город, аватар, «о себе», ссылки на соцсети (для художника).
- Удаление аккаунта из приложения (требование App Store и Google Play).

### Каталог
- Лента: «Новое», «Популярное», «Для вас» (по подпискам и избранному; ИИ — позже).
- Поиск по названию/описанию/имени художника.
- Фильтры: категория, стиль, техника, цена от–до, размер (макс. сторона), город художника.
- Сортировка: новые, цена ↑/↓, популярные.
- Карточка работы: галерея фото с зумом, размеры, материалы, техника, год, цена,
  художник, «в избранное», «написать художнику», «купить», расчёт доставки.

### Художник
- Добавление работы: до 10 фото (камера/галерея), поля из карточки, черновик/публикация.
- Редактирование, снятие с продажи, архив.
- Статистика: просмотры, добавления в избранное, продажи, выручка за месяц.
- Подписчики получают push о новой работе.

### Покупка (эскроу)
Статусы заказа:

```
awaiting_payment ─pay─▶ paid ─artist confirms (≤24 ч)─▶ confirmed ─ship + трек (≤48 ч)─▶ shipped ─buyer confirms─▶ completed
       │                  │                                │
       └──────────────────┴──────── cancelled ◀────────────┘
```
- `awaiting_payment` истекает через 30 мин → `cancelled`, работа снова в продаже.
- `paid` без подтверждения художника 24 ч → автоотмена и возврат.
- `confirmed` без отправки 48 ч → автоотмена и возврат.
- `shipped` без подтверждения покупателя 14 дней → автозавершение.
- Отмена: покупатель — до `confirmed`; художник — отказ на `paid`.
- При `completed` выплата художнику: цена − комиссия (статус выплаты `released`).
- Работа резервируется при создании заказа, становится `sold` при `completed`.

### Платежи, доставка, push, файлы — через интерфейсы с заглушками
| Сервис | Заглушка в MVP | Боевая реализация (позже) |
|---|---|---|
| Платежи | `stub`: кнопка «Тестовая оплата» в приложении | ЮKassa «Безопасная сделка» |
| Доставка | тарифная таблица из бизнес-плана | API СДЭК |
| Push | запись в лог + in-app уведомления | Expo Push (FCM/APNs) |
| E-mail | запись в лог | SMTP / Unisender |
| Файлы | локальный диск, раздача через API | S3 (Yandex Object Storage) |

### Общение и доверие
- Чат покупатель ↔ художник (по работе), realtime через WebSocket, история через REST.
- Отзыв с оценкой 1–5 после `completed`; рейтинг художника.
- Жалоба на работу/пользователя/сообщение; администратор скрывает контент.
- In-app уведомления (заказы, сообщения, новые работы подписок).

## 5. Вне MVP
AR-примерка, ИИ-рекомендации, сертификаты подлинности, B2B-кабинет и API, рассрочка,
Artista Academy, мультиязычность, веб-версия, программа лояльности, споры/возвраты после получения.

## 6. Нефункциональные требования
- iOS 15+, Android 8+ (минимум Expo SDK 58).
- Главный экран < 2 с на 4G; пагинация курсором.
- Пароли — bcrypt; все входные данные валидируются на сервере; rate limit на вход.
- Хранение данных в РФ (152-ФЗ): Postgres и файлы на российском хостинге.
- Покрытие тестами backend ≥ 80%.
